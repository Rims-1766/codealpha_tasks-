# 🌍 Translify – Language Translator

A modern and responsive language translation web application that helps users translate text between multiple languages instantly. Built with a clean UI and powerful translation capabilities, Translify makes communication across languages simple and efficient.

---

## ✨ Features

* 🌐 Translate text between multiple languages
* 🔄 Swap source and target languages
* 🎤 Voice input (Speech-to-Text)
* 🔊 Listen to translated text (Text-to-Speech)
* 📋 Copy translated text with one click
* 📱 Fully responsive design
* ⚡ Fast and user-friendly interface
* 🎨 Modern and attractive UI

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript
* Translation API
* Web Speech API

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone http://127.0.0.1:5501/index.html
```

### 2. Open the Project Folder

```bash
cd translify
```

### 3. Run the Application

Simply open `index.html` in your browser.

---

## 🎯 How It Works

1. Enter the text you want to translate.
2. Choose the source language.
3. Choose the target language.
4. Click the **Translate** button.
5. View the translated output instantly.
6. Use voice or copy features as needed.
